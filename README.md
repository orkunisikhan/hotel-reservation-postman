# Hotel Reservation API - Postman Collection

This repository contains a Postman collection created to test a Hotel Reservation API.

## 📌 Files

- `OtelRezervasyon.postman_collection.json` — Main Postman collection for API requests.

## 🚀 How to Use

1. Download the collection file.
2. Open Postman.
3. Click **Import**.
4. Select the JSON file.
5. Send requests and review the responses.

## 🔍 What is Tested

• Create reservation requests
• Retrieve reservation details
• API request and response validation
• Status code validation
• Basic request flow testing

📎 This project was created to practice API testing and improve QA skills.
