# Hotel Reservation API - Postman Collection

This repository contains a Postman collection created to practice API testing for a Hotel Reservation system.

## Project Purpose

The goal of this project is to improve API testing and QA skills by testing reservation-related endpoints using Postman.

## Features Tested

- Create reservation requests
- Retrieve reservation details
- Validate request and response flow
- Test reservation-related API functionality

## Validation Checks

- Status code validation
- Response body validation
- Request and response verification
- Basic error scenario checks

## Methods Used

- GET
- POST
- Postman Collections
- API Response Validation

## File

- `OtelRezervasyon.postman_collection.json` — Main Postman collection for API testing.

## How to Use

1. Download the collection file.
2. Open Postman.
3. Click **Import**.
4. Select the JSON file.
5. Run requests and review responses.

This project was created to strengthen API testing, Postman, and Manual QA skills.
